# SSH 자동접속

프로젝트 루트의 `config.json`을 채운 뒤 `START.cmd`를 실행합니다. DAY2, DAY3와 동일한 설정 파일을 사용합니다.

저장된 IP와 계정·비밀번호로 접속하고, 호스트 이름·계정·MAC을 확인합니다. 성공하면 루트 설정의 `last_verified_at`을 갱신하고 `whoami`, IP, MAC을 출력한 뒤 Pi 쉘을 유지합니다. 종료는 `exit`입니다.

접속 정보 입력창과 자동 IP 탐색은 없습니다. 실패하면 오류에 따라 루트 설정을 수정합니다. 검증 시각은 디버깅 참고용이며 실행 판단에 사용하지 않습니다.

Windows용 Plink는 최초 실행 시 다운로드·검증합니다. `.tools/`와 `.runtime/`은 Git에서 제외되며, 정상 종료와 처리된 오류에서는 임시 비밀번호 파일을 삭제합니다. 강제 종료 시에는 임시 파일이 남을 수 있습니다.

AI나 명령줄에서 접속 확인만 할 때는 `Connect-Pi.ps1 -VerifyOnly -NoHold`를 실행합니다. 이 모드는 실습 상태를 변경하지 않습니다.
